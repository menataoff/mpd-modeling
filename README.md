# Моделирование МПД-двигателя

Решатель рассчитывает осесимметричную идеальную МГД-модель в координатах
\((z,r,\varphi)\). Основной численный метод --- явная центральная схема
Лакса--Фридрихса. Она остаётся схемой расчёта во всех вариантах ниже.

## Запуск

Проект содержит файл flake.nix с необходимыми зависимостями: CMake, MPI,
OpenMP, VTK, yaml-cpp и exprtk.

    nix develop
    cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
    cmake --build build
    mpirun -np 1 ./build/mpd-plasma-dynamics config.yaml

Программа принимает путь к YAML-конфигурации первым аргументом. Результат
каждого запуска сохраняется в отдельном каталоге VTK-файлов.

## Изменение: внутренняя граница Г4 у ступеньки катода

### В чём была проблема

Изначально код умеет задавать граничные условия только на четырёх внешних
сторонах сетки: левом входе, правом выходе, аноде и внутренней границе.
Вертикальный торец резкой ступеньки под катодом --- Г4 --- является
внутренней границей. Если просто сделать геометрическую ступеньку, ячейки
сразу справа от её торца используют в разностном шаблоне значения из
неподходящей части предыдущей строки сетки. Это не является ни стенкой,
ни корректным входом газа.

### Что добавлено

Добавлен YAML-блок internal_step_boundary. Он задаёт положение и радиус
ступеньки, а также один из двух режимов:

    internal_step_boundary:
      enabled: true
      z: 0.400
      radius: 0.200
      mode: wall       # wall или inlet
      rho: 1.0         # используются только при mode: inlet
      v_z: 0.15
      e: 0.0373134
      H_phi_edge: 0.4

После обычного шага решателя первая строка плазмы справа от ступеньки
получает физическое состояние Г4:

- wall: закрытый торец катода, \(v_z=0\), остальные величины
  продолжаются из плазмы по нормали;
- inlet: газ входит вдоль \(+z\) с предписанными \(\rho,e,v_z\);
  \(v_r=v_\varphi=H_z=H_r=0\).

Для входа Г4 используется регулярное окружное поле

\[
H_\varphi(r)=H_{\varphi,c}\frac{r}{r_c},\qquad 0\le r\le r_c,
\]

поэтому \(H_\varphi(0)=0\). Это необходимо на оси: старый профиль
вида \(1/r\) там был бы бесконечным.

### Что принципиально не изменилось

- Уравнения идеальной МГД не заменялись.
- Центральный шаг Лакса--Фридрихса не заменялся другой схемой.
- Обычные ячейки и все внешние границы рассчитываются прежним способом.

Изменение локально: после центрального шага только строка, совпадающая с
Г4, получает граничное состояние. Для варианта с входом Г3 на Г4
накладывается стенка; для варианта с входом Г4 меняется лишь её
предписанное состояние.

## Поля без продольного компонента

В постановках без продольного поля задаются

\[
H_z=0,\qquad H_r=0.
\]

Это согласовано с условием \(\nabla\cdot\bm H=0\): при осевой симметрии
и \(H_z=0\) регулярное на оси радиальное поле может быть только нулевым.
Остаётся окружное поле \(H_\varphi\).
